MISSING CAPABILITIES (from original .g files, not yet in mrmind.py)
--------------------------------------------------------------------
These existed in the original weblab Gerbil-based system and were not
carried into the current ELIZA reconstruction:

a) 20 Questions game (MrMind/20Questions.g)
   A full structured multi-turn game: user thinks of a human attribute,
   MrMind asks yes/no questions probing it (does it involve family?
   is it constant? universal? necessary? unique to humans?).
   A real dialogue arc, not just pattern matching.

b) Human Quotient score (JB-added/HumanQuotient.g, ScoreMe.g,
   WinLoss.g, LexicalMath.g)
   A running numerical score tracking how "human" the user seems.
   LexicalMath.g implemented lexical increment/decrement up to 1000.
   Bot could comment on and update the score during conversation.

c) Repetition detection (JB-added/Repetition.g)
   Bot detected when user was repeating themselves and called it out.

d) Expression tracking (JB-added/ExpressionFilter.g,
   Defaults/defaults.g "Expressions repeater")
   Bot noted phrases/expressions the user used and could echo them
   back later in the conversation.

e) Probabilistic response selection (WantSomePointers.g "IfChance")
   Weighted-random selection from a pool of hints/suggestions, rather
   than strict cycling. Used when user was stuck.

f) User survey (MrMind/UserSurvey.g)
   Formal survey the bot could administer when user was stuck or
   explicitly asked for pointers. Referred to from multiple topics.
